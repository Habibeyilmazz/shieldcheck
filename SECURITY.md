# Security policy

To report a vulnerability in shieldcheck itself (for example an SSRF bypass in `serve`, or a way for a scanned site to inject content into a report), use GitHub's private advisory form: https://github.com/Habibeyilmazz/shieldcheck/security/advisories/new

Please do not open a public issue for it. This is a one-person project; expect a reply on a best-effort basis.

shieldcheck is a tool for auditing your own sites. Reports about a third-party site's security belong to that site's owner, not here.
